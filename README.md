# Accessible Portfolio — Thiranex Internship Task

A multi-page, responsive personal portfolio prepared around the task requirements for **HTML5 Semantic Structure & Accessibility**.

## Pages
- `index.html` — Home
- `about.html` — About and skills
- `projects.html` — Selected projects
- `contact.html` — Accessible contact form

## Features included
- Semantic landmarks: `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`
- Skip-to-main-content link
- Logical headings, page titles, descriptions, and document language
- Keyboard-visible focus styles
- Responsive navigation with `aria-expanded` and `aria-controls`
- Proper form labels, autocomplete attributes, required-field validation, and live status feedback
- Reduced-motion preference support
- Responsive layout for mobile, tablet, and desktop

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
3. Navigate through Home, About, Projects, and Contact.

## Test with Lighthouse
1. Open the site in Google Chrome.
2. Press `F12` and select **Lighthouse**.
3. Choose Mobile or Desktop and run Accessibility and SEO audits.
4. Fix any findings shown by the audit before submitting.

**Important:** Lighthouse scores depend on the browser, environment, and audit version. This project is structured to support strong scores, but no score is guaranteed until you run the audit. The contact form uses `mailto:` and does not send data to a backend server.

## Personalize before submission
- Review the project descriptions and replace anything that does not accurately represent your work.
- Update the LinkedIn destination if you have a direct profile URL.
- Add a real profile photo only if you want one; use descriptive `alt` text for meaningful images.
